# Changelog

## 1.0.0 — 2026-11-08

Первый публичный релиз.

- Добавлены Greater/Perfect версии сфер и правила минимального уровня модификатора с fallback.
- Добавлены эссенции и Alloy с эффектами по базе и лимитом crafted-модов.
- Добавлены совместимые омены с проверкой пересечения ограничений и записью каждого расхода.
- Реализованы отмена, раскол, Divine и освящение; закреплённые моды защищены от обычного снятия и переброса.
- Реализованы кости Бездны, скрытые моды, раскрытие из реально предложенных вариантов и Putrefaction.
- Добавлены качество, катализаторы, настои, гнёзда и Augment.
- Добавлена ручная фиксация непредсказуемых/особых исходов, отдельные Standard/архивные ограничения.
- Добавлены отмена шага, сохранение новых признаков в JSON и автономный HTML без установки.
- Добавлены автоматические проверки правил и GitHub Actions.

Границы: без RNG-симуляции, точных вероятностей, рыночной оптимизации и автоматического расчёта полного DPS/защит. Непредсказуемые и исторические операции используют ручной итог из игры. Подробности: README и docs/MECHANICS.md.
