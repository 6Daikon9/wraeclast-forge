# Wraeclast Forge · PoE2 Craft

Русскоязычный пошаговый помощник крафта экипировки **Path of Exile 2**.

**База → цели → валюта и омены → действие в игре → реальный результат → следующий шаг.**

## Скачать и запустить

В [Releases](https://github.com/6Daikon9/wraeclast-forge/releases) скачайте `WraeclastForge-v1.0.0.zip`, распакуйте и откройте `WraeclastForge-v1.0.0.html` в современном браузере. Установка, Node.js и интернет для автономной сборки не нужны. Данные и изображения включены в файл.

Проекты сохраняются в браузере на вашем устройстве. Для переноса между браузерами, файлами и онлайн-версией используйте экспорт/импорт JSON. Перед очисткой данных браузера экспортируйте проекты.

## Возможности

- 1435 баз в 41 отдельном пуле оружия, украшений и брони. Пулы брони разделены по атрибутам.
- Текущие префиксы/суффиксы, цели по семейству и минимальному тиру, стартовые наборы статов.
- Обычные, Greater и Perfect Transmutation/Augmentation/Regal/Exalted/Chaos с правилами Minimum Modifier Level и исключением для старшего доступного тира семейства.
- Alchemy, Annulment, Fracturing, Divine; признаки fractured/crafted/desecrated у каждого мода.
- Совместимые омены: сторона добавления/удаления, двойное добавление/снятие, Whittling, Light, кристаллизация, освящение и другие эффекты.
- Эссенции всех представленных в каталоге рангов, corrupted-эссенции и Alloy с гарантированным эффектом конкретной базы и проверкой crafted-лимита.
- Бездна: кости, скрытые моды, ввод предложенных вариантов и раскрытие, Abyssal Echoes, Putrefaction, особые пулы lich-модов.
- Качество, катализаторы, Vaal Infusers, гнёзда и установка/замена рун, ядер и других Augment из пула базы.
- Особые операции: Vaal, Architect, Sacrifice, Chance, Mirror, Lock, Flux сопротивлений, Perfect Flux и рунная ковка.
- Журнал расходов с зафиксированными ручными курсами, совместная запись исхода и затрат, отмена последнего шага, копирование проектов и JSON.

## Уровни поддержки и ограничения

Помощник **не взаимодействует с клиентом игры и не генерирует RNG**. Реальный исход вводит игрок. Обычные операции проверяют редкость, вместимость, семейства, тиры, признаки модов и выбранные омены перед атомарной записью.

Для непредсказуемых Vaal/Architect, рунной ковки, преобразования сопротивлений и исторической рекомбинации используется ручной ввод полного наблюдённого состояния. Эти действия не являются предсказанием результата. Для Flux сохраняются отдельные экземпляры переведённых сопротивлений; таблицы эквивалентности не симулируются. Рецепт и материалы рунной ковки записываются пользователем, автоматическая цена рецепта не вычисляется.

Три режима: текущая лига, Standard и архив. Отключённый Recombinator доступен только для записи исторического результата. Standard-only/больше не получаемые омены ограничены соответствующим режимом. Наличие записи в PoE2DB не гарантирует доступность в вашей лиге.

Рекомендации — маршрут по правилам и целям. Минимальная рыночная цена, точные шансы, DPS, все масштабирования от качества и математически оптимальный маршрут не рассчитываются. Homogenising использует явные теги аффиксов; границы верификации описаны в [матрице механик](docs/MECHANICS.md). Для специальных баз максимум гнёзд задаётся явно в состоянии вещи.

Каталог ориентирован на экипировку. Карты, самоцветы, навыки, флаконы и обработка валюты как отдельного предмета не смешиваются с пулами модов экипировки. T1 — старший тир соответствующего семейства в снимке; это не утверждение о патче.

## Разработка

Нужен Node.js 22+; внешних npm-зависимостей нет.

```sh
npm start
# http://127.0.0.1:4173
npm test
npm run build:portable
```

Сборка создаётся в `outputs/portable/`. Онлайн-приложение — обычная статика в `dist/`; её можно разместить на любом статическом хостинге.

Обновление данных требует сети:

```sh
node scripts/fetch-data.mjs --refresh
node scripts/fetch-crafting.mjs
node scripts/extract-crafting.mjs
node scripts/fetch-assets.mjs
npm test
npm run build:portable
```

Обновление источника может изменить идентификаторы модов. Перед обновлением экспортируйте проекты и проверьте миграцию. Не заменяйте дату снимка в документации без повторной проверки источников.
